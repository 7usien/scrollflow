# ScrollFlow — إضافة مؤشر تقدّم القراءة واستعادة الموضع (Manifest V3)

إضافة Chrome عصرية وخفيفة تُظهر مؤشر تقدّم قراءة رأسيًا، تحفظ موضع التمرير لكل صفحة، وتحتفل بـ Confetti لطيف عند النهاية.

- **صفر مكتبات runtime:** لا React، لا Lodash، ولا canvas-confetti. حزمة فائقة الخفة (< 20KB).
- **صفر طلبات شبكة:** خصوصية تامة؛ كل البيانات محلية ولا ترسل أي شيء لخوادم خارجية.
- **عزل تام:** كل عناصر الواجهة مبنية داخل Shadow DOM واحد مع `:host { all: initial }`.
- **أداء استثنائي:** مستمع تمرير وحيد `passive` مع حلقة `requestAnimationFrame` وتنعيم `lerp(0.28)`.

---

## 🚀 التثبيت والتشغيل المحلي في Chrome

1. **بناء المشروع:**
   ```bash
   npm install
   npm run build
   ```
2. **تحميل الإضافة في المتصفح:**
   - افتح المتصفح وتوجّه إلى `chrome://extensions`.
   - فعّل **وضع مطوّر البرامج (Developer mode)** في الزاوية العلوية.
   - انقر على **تحميل حزمة غير مضغوطة (Load unpacked)**.
   - اختر المجلد `dist/` داخل هذا المشروع.
3. **التجربة:**
   - افتح أي صفحة طويلة (مثل ويكيبيديا أو MDN أو مقال إخباري).
   - ستشاهد مؤشر القراءة الرأسي على الحافة.
   - مرّر للأسفل لرؤية حركة المؤشر ونبضات المحطات والاحتفال عند النهاية.
   - أعد تحميل الصفحة لترى الاستعادة التلقائية مع تلميح «عدت إلى حيث توقفت».
   - انقر أيقونة الإضافة لفتح نافذة البوب-أب التفاعلية وتخصيص الثيمات والمواقع المستثناة.

## 🛠️ أوامر التطوير والتحقق

```bash
npm run dev          # بناء مراقب للتطوير (Watch mode)
npm run build        # إنتاج مجلد dist/ الجاهز للتحميل
npm run typecheck    # فحص الأنواع الصارم (tsc --noEmit)
npm run lint         # فحص الكود والتنسيق (eslint)
npm run test         # تشغيل 31 اختبار وحدة (vitest)
npm run test:e2e     # تشغيل 10 سيناريوهات تكاملية في متصفح حقيقي (playwright)
npm run verify       # فحص شامل (typecheck + lint + test)
```
