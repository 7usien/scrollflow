1 الملخص في سطر واحد

عهد الخصوصية الصارم: إضافة ScrollFlow لا تجمع، ولا تسجل، ولا تشارك أي بيانات شخصية أو سجلات تصفح إطلاقاً. ملاحظاتك وهوامشك ومواضع قراءتك تبقى ملكك وحدك داخل مساحة التخزين المحلية لمتصفحك.

2 مصفوفة معالجة وتخزين البيانات

يوضح الجدول التالي كافة البيانات الفنية التي تتعامل معها الإضافة وكيفية معالجتها:

نوع البيانات الغرض الفني والتشغيلي مكان المعالجة والحفظ
ارتفاع الصفحة وموضع التمرير حساب نسبة القراءة وعرض الشريط واستعادة موضعك عند العودة chrome.storage.local محلياً فقط
رابط الصفحة (مطبَّعاً) مفتاح فهرسة محلي لربط موضع التمرير والهوامش بالصفحة chrome.storage.local محلياً فقط
هوامش النصوص وتظليلها (5 ألوان) حفظ الاقتباسات وإظهار نقاط المسار وبطاقات المعاينة السريعة chrome.storage.local محلياً فقط بمفتاح منفصل
فهرس العناوين (Auto-TOC) استخراج عناوين H1..H3 لرسم فصول المقال وشُرط الشريط ذاكرة RAM المؤقتة لا يُخزَّن دائماً
تصدير الملاحظات لـ Markdown نسخ هوامش المقال إلى الحافظة (Clipboard) لتطبيقات Notion وObsidian حافظة النظام المباشرة بنقرة واحدة صريحة
مؤقت وضع الزن (Zen Auto-Hide) إخفاء الشريط عند التوقف عن التمرير لمدة 2.5 ثانية للتركيز ذاكرة RAM المؤقتة
إحصائيات الصفحة (الكلمات والشاشات) تقدير وقت القراءة وعمق الصفحة في نافذة الإضافة في الذاكرة المؤقتة فقط — لا يُخزن نص المقال
تفضيلات المظهر والإعدادات حفظ الثيم المختار، موضع الشريط، وقائمة المواقع المستثناة chrome.storage.local محلياً فقط

3 ما لا نفعله بشكل قاطع (محظورات التصميم)

  • لا خوادم خارجية: لا نمتلك ولا نتصل بأي سيرفر أو خادم سحابي عن بُعد.
  • لا تتبع ولا تحليلات: لا نستخدم Google Analytics، ولا Mixpanel، ولا أي أداة لتحليل سلوك المستخدم.
  • لا تلصص على البيانات الحساسة: لا نقرأ حقول الإدخال، ولا كلمات المرور، ولا البطاقات الائتمانية.
  • لا بيع أو مشاركة للبيانات: لا نبيع أو نشارك أو نؤجر أي بيانات لأي شركة إعلانات أو جهات خارجية.
  • لا حسابات ولا تسجيل دخول: لا نطلب بريداً إلكترونياً أو اسماً، وتعمل الإضافة فور تثبيتها بلا قيود.

4 سياسة الاحتفاظ والتحكم الكامل في البيانات

أنت صاحب القرار الأول والأخير فيما يتم حفظه على جهازك:

  • زر المسح الفوري: يتوفر زر في نافذة الإضافة وصفحة الخيارات لمسح جميع المواضع والهوامش المحفوظة فوراً.
  • تنظيف تلقائي دوري (LRU Pruning): تُحذف مواضع الصفحات غير المزارة تلقائياً بعد مرور 90 يوماً، مع سقف أقصى 1500 صفحة.
  • إزالة شاملة وفورية: عند إزالة الإضافة من المتصفح، يحذف Chrome تلقائياً كافة بياناتها المخزنة دون أي بقايا.

5 الأذونات الفنية وتبريرها الصارم

الإذن المطلوب سبب الحاجة إليه في الإضافة
storage لحفظ الإعدادات والمواضع والهوامش محلياً داخل المتصفح عبر chrome.storage.local.
activeTab لقراءة رابط التبويب الحالي عند فتح نافذة الإضافة لحساب وقت القراءة وإتاحة خيار استثناء الموقع.
webNavigation لرصد تغيير المسارات في تطبيقات الصفحة الواحدة (SPAs كـ React وVue) لحفظ واستعادة الموضع لكل مسار بدقة.
<all_urls> (الوصول للمواقع) لتشغيل شريط القراءة وكبسولة التظليل في أي مقال تقرأه، مع استبعاد حتمي لمتجر كروم والصفحات الداخلية للمتصفح.

6 الامتثال للسياسات العالمية والشفافية

تلتزم الإضافة التزاماً كاملاً بجميع المعايير والسياسات التالية:

  • سياسة الغرض الأحادي لمتجر كروم (Single Purpose Policy): تركز الإضافة حصرياً على تحسين تجربة القراءة وتدوين الهوامش.
  • اللائحة الأوروبية لحماية البيانات (GDPR): التزام تام عبر مبدأ الخصوصية بالامتناع عن المعالجة (Zero Data Processing).
  • قانون خصوصية المستهلك في كاليفورنيا (CCPA): لا نجمع ولا نبيع أي معلومات للمستهلكين.

1 Executive Summary

Our Absolute Privacy Pledge: ScrollFlow does not collect, track, transmit, or share any personal information or web browsing activity whatsoever. Your reading progress, margin notes, and saved scroll positions remain strictly under your control inside your local browser storage.

2 Data Processing Matrix

The table below provides a full breakdown of technical data handled by ScrollFlow and where it is processed:

Data Type Technical & Operational Purpose Storage Location
Page Height & Scroll Percentage Computes reading percentage, renders the progress bar, and restores position upon return chrome.storage.local (Local Only)
Normalized Page URL Acts as a local dictionary key to associate scroll coordinates and margin notes with the page chrome.storage.local (Local Only)

Reading Metrics (Words & Viewports) Calculates estimated reading time and page screen depth inside the popup Transient RAM Only (Never persisted)
User Settings & Themes Saves chosen theme, bar geometry, Zen mode toggle, and whitelisted/blacklisted domains chrome.storage.local (Local Only)

3 What We Never Do (Architectural Boundaries)

  • No Remote Servers: We do not operate or communicate with any cloud server or database.
  • No Telemetry or Tracking: No Google Analytics, no telemetry beacons, no user fingerprinting.
  • No Access to Sensitive Fields: We never inspect form inputs, passwords, or financial credentials.
  • No Data Monetization: We do not sell, license, share, or broker user data with third parties.
  • No User Accounts: No sign-in, no email registration, and no user profiles required.

4 Data Retention & User Control

You have sovereign control over all data stored locally on your machine:

  • One-Click Manual Purge: A clear "Clear Stored Data" button is available in the popup and options page.
  • Automatic LRU Pruning: Inactive pages older than 90 days are automatically deleted, with a strict 1,500-page cap.
  • Total Removal upon Uninstall: Uninstalling ScrollFlow immediately and permanently wipes all extension storage in Chrome.

5 Technical Permission Justifications

Declared Permission Exact Technical Justification
storage Used strictly to persist user display options, scroll coordinates, and margin notes locally via chrome.storage.local.
activeTab Invoked only when opening the popup to read the current tab's URL/title for reading metrics and domain toggling.
webNavigation Detects Single Page Application (SPA) route changes via HTML5 History events to preserve positions per route.
<all_urls> (Host Access) Enables the reading bar and margin highlights on user-selected reading material, with strict exclusions for Chrome Web Store and internal browser schemes.

6 Regulatory & Policy Compliance

ScrollFlow strictly aligns with all leading developer and privacy standards:

  • Chrome Web Store Single Purpose Policy: Exclusively focused on reading enhancement and annotation.
  • European GDPR: Maximum compliance achieved through complete absence of personal data processing.
  • California CCPA: Zero consumer data collection, selling, or sharing.
